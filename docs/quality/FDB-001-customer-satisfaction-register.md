## 1. Purpose

To record what clients say about the work, so that satisfaction is measured from evidence rather than impression, and so recurring complaints trigger action.

## 2. What gets recorded

Every piece of client feedback, whether solicited or not:

- Responses to the post-handover feedback request (§4)
- Complaints, however informally raised — "this isn't quite what I expected" counts
- Unprompted praise, including referrals and repeat business
- Reasons given for declining a quote (from lost leads)

Record feedback as received, in the client's own words where possible. Paraphrasing loses the signal.

## 3. Register

> **No entries yet.** This register begins collecting at the next project handover. Rows are added as feedback is received.

| # | Date | Client | Project | Source | Rating (1–5) | Feedback | Action taken | CAPA raised |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

**Column notes**

- **Source** — post-handover request, email, call, WhatsApp, unprompted, lost-lead reason
- **Rating** — where given. Leave blank rather than guessing
- **Action taken** — what was done in response, or "none required"
- **CAPA raised** — reference of any corrective action, where the feedback indicated a systemic problem

## 4. Collecting feedback

At project closure (SOP-DEL-001 §5.9), ask the client three questions:

1. Did the finished site do what you expected it to do?
2. Was anything about how we worked together frustrating?
3. Would you recommend us to someone else? *(1–5)*

Three questions get answered. Ten do not.

Ask by whichever channel the client already uses. Record the response here the same day.

## 5. Using the register

At each management review (QMS-2026-MRV-001):

1. Count entries received since the last review.
2. Identify any theme appearing more than once — the same complaint twice is a process problem, not a client problem.
3. Raise a corrective action for any theme that recurs.
4. Note the average rating and whether it is moving.

A register that is only read at review time still works. A register that is never filled in does not.
